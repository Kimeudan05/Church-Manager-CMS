Announcement Creation Guide
Priority Levels:
  • Urgent - Critical announcements requiring immediate attention (e.g., emergencies, urgent meetings)
  • High - Important announcements (e.g., event changes, important reminders)
  • Normal - Regular church announcements (e.g., weekly events, general updates)
  • Low - Informational announcements (e.g., newsletter updates, general information)
Targeting Options:
  • Church Wide: Visible to all church members
  • Target Groups: Visible only to members of selected groups
  • Target Members: Visible only to selected individuals
  • Mixed Targeting: Combine groups and members for specific audiences
Scheduling Tips:
  • Publish Date: Set when the announcement should become visible
  • Expiry Date: Optional - set when announcement should automatically expire
  • Draft Mode: Save without publishing for later editing
  • Scheduled Publishing: Set future publish date for automatic publishing
Best Practices:
  • Keep titles clear and descriptive
  • Use appropriate priority levels
  • Target announcements to relevant audiences
  • Schedule announcements for optimal visibility
  • Set expiry dates for time-sensitive announcements
